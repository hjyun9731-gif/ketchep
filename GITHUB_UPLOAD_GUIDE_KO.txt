강원 화물협회 자동화 v2.1 Simple 배포

1. 이 ZIP의 압축을 풉니다.
2. 기존 GitHub 저장소의 파일을 이 폴더 내용으로 교체합니다.
3. GitHub Desktop에서 변경 내용을 확인합니다.
4. 커밋 메시지에 `v2.1 단순 화면 및 기존 명단 업로드`를 입력합니다.
5. Commit → Push origin을 누릅니다.
6. Railway가 GitHub 저장소와 연결돼 있으면 자동으로 재배포됩니다.

배포 후 확인 순서
- 로그인
- 첫 화면 상단의 `기존 명단 불러오기` 버튼 확인
- 전체면허자현황 + 미수금 파일 선택
- 현재명단 인원 확인
- 카드결제 화면에서 알토란/사이다페이 업로드 확인

주의
- 실제 회원 파일, 통장 파일, 비밀번호, .env는 GitHub에 올리지 않습니다.
- 기존 PostgreSQL DB를 그대로 사용합니다. 이번 버전은 모델 변경이 없어 별도 migration이 없습니다.
