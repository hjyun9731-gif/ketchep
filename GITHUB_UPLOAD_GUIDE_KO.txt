화물협회 자동화 프로그램 GitHub 업로드 방법
=============================================

1. freight_association_github_ready_v2.0.zip 압축을 풉니다.

2. 압축을 푼 폴더 안에 아래 파일이 바로 보여야 합니다.
   manage.py
   requirements.txt
   Dockerfile
   railway.json
   core
   config
   templates

3. GitHub Desktop을 실행하고 로그인합니다.

4. File → Add Local Repository → Choose를 누르고 압축을 푼 폴더를 선택합니다.

5. Git 저장소가 아니라는 안내가 나오면 create a repository를 누릅니다.

6. 아래처럼 입력합니다.
   Name: freight-association-system
   Description: 화물협회 입금대조 미수금 입금전표 자동화
   Git ignore: None
   License: None

7. Create Repository를 누릅니다.

8. 상단 Publish repository를 누릅니다.

9. Keep this code private를 반드시 체크한 상태로 Publish합니다.

10. GitHub 저장소 첫 화면에 아래가 보이면 완료입니다.
    core/
    config/
    docs/
    templates/
    Dockerfile
    manage.py
    railway.json
    requirements.txt
    README.md
