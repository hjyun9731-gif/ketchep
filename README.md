# 화물협회 입금대조·미수금·입금전표 자동화

농협 입금내역을 계좌별로 복사해 붙여넣으면 회원을 자동 대조하고, 미수금·통장 K~O열·입금전표를 동시에 갱신하는 Django 웹프로그램입니다.

화면은 한국형 재무회계 SaaS인 **그랜터의 업무형 UI 문법**을 참고해 구성했습니다. 좌측 내비게이션, 낮은 채도의 카드, 숫자 요약, 밀도 높은 거래표, 확인 필요 중심 흐름을 사용하되 그랜터의 로고·상표·고유 그래픽은 복제하지 않았습니다.

## v2.0 핵심 업무 흐름

매일 사용자가 하는 일은 아래가 전부입니다.

```text
농협 계좌 1 거래내역 전체 복사 → 계좌 1 칸에 Ctrl+V
농협 계좌 2 거래내역 전체 복사 → 계좌 2 칸에 Ctrl+V
농협 계좌 3 거래내역 전체 복사 → 계좌 3 칸에 Ctrl+V
→ 확실한 거래 자동처리
→ 애매한 거래만 확인
```

매일 전날부터 오늘까지 겹치게 조회해 붙여넣어도 기존 거래는 다시 반영하지 않습니다. 월요일에 금요일부터 월요일까지 붙여넣는 방식도 그대로 사용할 수 있습니다.

## 자동 처리 결과

한 번의 입금 확정으로 다음 세 결과가 동시에 생성됩니다.

- 미수금
  - 같은 달 입금액 합산
  - 입금날짜는 입금 건수만큼 모두 기록
  - 같은 날 두 번 입금하면 같은 날짜도 두 번 기록
- 통장
  - K열 지역
  - L열 차량번호
  - M열 이름
  - N열 계정
  - O열 금액
- 입금전표
  - 거래별 전표번호
  - 보통예금 차변
  - 협회비·관리비·잡수입·가수금 대변
  - 한 입금을 여러 계정으로 나누면 같은 전표번호로 여러 줄 생성

이번 달 다운로드 버튼은 다음 파일 3개를 ZIP으로 생성합니다.

```text
2026년 통장_완성본.xlsx
2026년 8월 미수금_완성본.xlsx
2026년 8월 입금전표_완성본.xlsx
```

## 입금자 자동매칭 규칙

순서대로 검색하며, 확실한 경우만 자동 반영합니다.

1. 사용자가 저장한 입금자 별칭
2. 현재·과거 전체 차량번호
3. 이름 + 차량번호 일부 또는 끝번호
4. 미수금 비고의 이름 + 차량번호 일부
5. 차량 끝번호가 전체에서 유일한 경우
6. 이름이 전체에서 유일한 경우
7. 미수금 비고의 이름 단독 일치

다음 형태를 처리합니다.

```text
1423홍길동
홍길동1423
1423
81배1845
김창훈1116호
가뭔1025
한 순 례
```

미수금 비고만으로 찾은 거래는 자동 반영하지 않고 확인 목록에 보여줍니다. `홍길동`, `신평`, `한 순 례`처럼 자유롭게 적힌 비고도 공백과 구분기호를 제거해 검색합니다.

다음은 자동 확정하지 않습니다.

- 동명이인
- 동일 끝번호 차량 복수
- 이름과 차량번호가 서로 다른 회원을 가리키는 경우
- ATM·일반이체·지로 등 식별정보가 없는 경우
- 미수금 비고 단독 일치
- 구별할 정보가 부족한 중복 의심 거래

수동 확인 시 `앞으로 같은 입금자명을 자동매칭`을 체크하면 해당 농협 계좌별 별칭을 저장합니다.

## 명단 관리

### 현재명단

현재 관리 중인 사람만 표시합니다.

- 정상 부과 중
- 최초 부과 전
- 완납
- 미수금 있음
- 선납금 있음

신규 명단은 지역·차량번호·성명 중심으로 간편 추가하고 상세정보는 나중에 보완할 수 있습니다.

### 폐업명단

폐업 처리 즉시 현재명단에서 빠지고 폐업명단으로 이동합니다. 자료는 삭제하지 않습니다.

- 기존 미수금 유지
- 폐업 후 입금대조 가능
- 선납금 환불대기
- 폐업자용 문자
- 동일인 재등록 시 과거 기록 연결

## 개별 부과일

월초 일괄 부과가 아니라 사람별 기준일에 부과합니다.

- 협회가입자: 실제 가입일 한 달 뒤 같은 날짜부터 협회비
- 비회원 관리비 대상: 자격증명 발급일 한 달 뒤 같은 날짜부터 관리비
- 없는 날짜는 그달 말일
- 8월 30일 등록자는 9월 1일이 아니라 9월 30일 최초 부과
- 미래 부과일은 미리 부과하지 않음
- 폐업월 부과 취소, 이후 부과 중지

협회비와 관리비는 한 사람에게 동시에 존재하지 않습니다.

## 자격증명 발급비

- 협회가입자: 면제
- 비회원 택배 `배`: 30,000원
- 비회원 비택배: 50,000원

택배 비회원이 50,000원을 입금하면 자격증명 발급비 30,000원과 관리비 선납 20,000원으로 나눌 수 있습니다. 신규 신청자는 발급비 납부 확인 후 기존 협회관리시스템 예정자에 등록하고 자격증명을 발급합니다. 이 프로그램은 기존 협회관리시스템을 대체하지 않으며 입금·미수금·전표 자동화 명단을 별도로 관리합니다.

## 알토란·사이다페이

- 결제내역 엑셀 업로드
- 차량번호 1순위, 이름 2순위 검증
- 차량번호와 이름 충돌 시 확인 필요
- 회원에게 총 결제금액 반영
- 농협 순정산입금은 회원에게 재반영하지 않음
- 총결제액 - 순정산액 = 카드수수료
- 사이다페이 승인번호·거래번호 우선 중복키
- 알토란은 일시·차량번호·이름·금액 조합

## 기타 기능

- 협회 가입·탈퇴
- 차량번호 변경 및 과거 차량 이력
- 동일인 재등록, 가족 승계, 일반 양도양수
- 선납금과 폐업 환불
- 미수금 문자 즉시·예약 발송
- 내용증명 및 배송결과
- 모든 변경이력 `admin` 기록

## 로컬 실행

Python 3.12 이상을 권장합니다.

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
copy .env.example .env  # Windows
# cp .env.example .env  # macOS / Linux

python manage.py migrate --run-syncdb
python manage.py bootstrap_admin
python manage.py seed_defaults
python manage.py runserver
```

접속 주소: `http://127.0.0.1:8000/`

기본 계정:

```text
아이디: admin
비밀번호: admin1234
```

## GitHub에 올리는 방법

ZIP 파일 자체를 저장소에 올리지 말고 압축을 푼 폴더 안의 파일 전체를 올립니다.

GitHub Desktop 기준:

```text
File
→ Add Local Repository
→ 압축을 푼 폴더 선택
→ create a repository
→ Name: freight-association-system
→ Create Repository
→ Publish repository
→ Keep this code private 체크
```

저장소는 반드시 Private으로 생성합니다. `.env`, 실제 회원 엑셀, 실제 통장 파일, 발송닷컴 비밀번호는 올리지 않습니다. `.gitignore`에 `media/`, `.env`, SQLite 파일이 제외되어 있습니다.

자세한 절차는 `GITHUB_UPLOAD_GUIDE_KO.txt`를 확인하세요.
