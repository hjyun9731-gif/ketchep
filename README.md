# 강원 화물협회 입금·미수금 자동화 v3.0

농협 입금내역을 계좌별로 복사해 붙여넣으면 회원을 자동 대조하고, 미수금·통장 K~O열·입금전표를 함께 갱신하는 Django 웹프로그램입니다.

v3.0은 부분 수정이 아니라 **사용자 화면 전체를 다시 만든 버전**입니다. 기존 기능은 유지하고 화면 구조, 메뉴, 검색, 표, 폼, 버튼과 업무 순서를 하나의 기준으로 통일했습니다.

## 일반 사용 메뉴

상단에는 실제로 자주 쓰는 다섯 메뉴만 표시합니다.

```text
입금대조 | 명단 | 카드결제 | 미수금 | 문자
```

자료 불러오기, 환불관리, 내용증명과 변경이력은 오른쪽 `관리` 메뉴에 정리했습니다.

## 매일 하는 업무

```text
농협 계좌 1 거래내역 전체 복사 → 계좌 1 칸에 Ctrl+V
농협 계좌 2 거래내역 전체 복사 → 계좌 2 칸에 Ctrl+V
농협 계좌 3 거래내역 전체 복사 → 계좌 3 칸에 Ctrl+V
→ 확실한 거래 자동처리
→ 애매한 거래만 확인
```

겹치는 기간을 다시 붙여넣어도 기존 거래를 중복 반영하지 않습니다.

## 기존 명단 이관

처음 한 번만 `관리 → 기존 자료 불러오기`에서 아래 두 파일을 선택합니다.

1. 전체면허자현황
2. 미수금 파일

기존 사람을 한 명씩 입력하지 않습니다. 차량번호·이름·생년월일 등으로 자동 연결하고 애매한 건만 확인 대상으로 남깁니다.

## 자동 처리 결과

입금 한 건을 확정하면 다음 결과가 같이 갱신됩니다.

- 미수금: 입금액 합산, 입금일 건별 기록
- 통장: K 지역, L 차량번호, M 이름, N 계정, O 금액
- 입금전표: 거래별 차변·대변 전표

월별 다운로드 파일:

```text
2026년 통장_완성본.xlsx
2026년 8월 미수금_완성본.xlsx
2026년 8월 입금전표_완성본.xlsx
```

## 명단과 부과

- 현재 관리 중인 사람은 현재명단에 표시
- 폐업 처리하면 현재명단에서 빠지고 폐업명단으로 이동
- 자료와 과거 미수금·입금내역은 삭제하지 않음
- 사람별 가입일 또는 자격증명 발급일을 기준으로 개별 부과
- 8월 30일 등록자는 9월 1일이 아니라 9월 30일 최초 부과

## 카드결제

알토란과 사이다페이에서 내려받은 엑셀을 그대로 올립니다.

- 차량번호 우선 자동대조
- 총결제액을 회원에게 반영
- 수수료와 순정산액은 별도 관리
- 승인번호·거래정보로 중복 방지
- 충돌하거나 애매한 건만 확인

## 문자발송

문자 업무는 다음 순서로 통일했습니다.

```text
대상 선택 → 납부기한·발송시점 설정 → 최종 문구 확인 → 발송
```

## 로컬 실행

Python 3.12 이상 권장:

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# macOS / Linux
source .venv/bin/activate

pip install -r requirements.txt
python manage.py migrate --run-syncdb
python manage.py ensure_v2_schema
python manage.py bootstrap_admin
python manage.py seed_defaults
python manage.py runserver
```

접속 주소: `http://127.0.0.1:8000/`

기본 계정:

```text
아이디: admin
비밀번호: admin1234
```

## GitHub 및 Railway

ZIP 압축을 푼 뒤 폴더 안의 파일 전체를 기존 GitHub 저장소에 덮어쓰고 커밋·푸시합니다. 저장소는 Private으로 유지하고 `.env`, 실제 회원자료, 통장파일과 문자발송 비밀번호는 올리지 않습니다.

Railway는 GitHub 푸시 후 자동 배포됩니다. 배포가 끝나면 브라우저에서 `Ctrl+F5`로 새로고침합니다.

## 검증 상태

- Python 전체 구문 검사 통과
- 모든 템플릿 기본 구조 검사 통과
- 모든 템플릿의 URL 이름 존재 여부 검사 통과
