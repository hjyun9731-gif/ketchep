# v4.1.0

- 회원 수정의 공문주소 수동관리 체크박스 제거, 주소 입력을 한 줄형으로 통일
- 원본에 가입표시 O만 있고 가입일이 없으면 임의 날짜를 만들지 않고 `가입일자 미상` 표시
- 폐업 버튼을 `폐업/양도/이관` 처리 선택 팝업으로 변경
- 양도는 도내 양도양수만 지원하고 팝업에서 접수일/인가일/처리일과 양수자 정보를 입력
- 사이다페이 `결제리스트.xls` 및 정산내역 형식, 알토란 `07.09.xlsx` 실제 헤더 지원
- 결제취소 사이다페이 행 제외, 수수료 누락 시 판매금액-정산금액으로 계산
- 미수금 지역/계정/금액대/완납여부 필터 및 100건 페이지 처리
- 은행 확인목록의 존재하지 않는 카드사 표시 필드 참조 제거
- 발송닷컴 자격증명은 환경변수만 사용하도록 유지(비밀번호는 코드/ZIP에 저장하지 않음)
