# v3.0.4 성능 개선

## 명단 화면
- 2,000명을 한 번에 렌더링하던 방식을 50명 단위 페이지로 변경
- 회원마다 차량번호·미수금을 따로 조회하던 N+1 쿼리 제거
- 현재 차량번호와 미수금 합계를 DB 한 번의 목록 쿼리에서 계산
- 현재명단·폐업명단 공통 적용

## 미수금 문자
- 전체 회원을 순회하며 회원별 미수금을 조회하던 구조 제거
- 미수금이 있는 대상만 DB에서 바로 추출
- 차량번호·미수금 표시 시 추가 쿼리 제거

## 기존 자료 불러오기
- Excel 행을 한 건씩 DB에 저장하던 ParsedRow 저장을 750건 단위 bulk_create로 변경
- 전체면허자현황 처리 시 기존 회원·차량·가입이력을 한 번에 미리 읽도록 변경
- 미수금 기초 부과금과 회원정보 갱신을 bulk_create/bulk_update로 변경

## 데이터베이스
- 기존 Railway DB에도 자동으로 적용되는 복합 인덱스 4개 추가
