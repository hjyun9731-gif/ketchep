# v2.2.0 — 업무순서형 UI 재설계

- 미수금 문자 화면을 `대상 선택 → 발송 설정 → 최종 확인` 순서로 재구성
- 페이지 전체를 차지하던 긴 검색·선택 필드를 제거하고 2열 작업 화면으로 변경
- 즉시/예약 발송을 선택형 카드로 표시
- 선택 인원 실시간 표시, 발송 불가 사유를 대상자 행에 바로 표시
- 문자 첫 화면을 미수금 문자·환불 문자 업무 선택 화면으로 변경
- 입금 처리내역과 미수금 화면 검색영역을 한 줄의 짧은 도구막대로 변경
- 전체 콘텐츠 너비를 1180px로 제한하고 헤더·간격·버튼 크기를 재조정
- 예약일시가 있으면 예약 초안, 없으면 즉시발송 초안으로 생성되도록 수정
