# UI/UX 스타일 가이드 — Granter 계열 업무형 SaaS 레이아웃

## 적용 범위

기존 화물협회 업무 로직은 유지하면서 화면 체계를 다음 방향으로 전면 개편했다.

- 좌측 2단 내비게이션: 아이콘 레일 + 상세 메뉴
- 상단 유틸리티 바와 현재 위치 표시
- 흰색·연회색 중심의 저채도 업무형 화면
- 얇은 테두리, 작은 라운드, 평면형 카드
- 숫자 중심 요약 카드와 밀도 높은 데이터 테이블
- 상태별 배지, 검토 대상 강조, 빠른 업무 진입
- 태블릿·모바일용 슬라이드 메뉴

## 디자인 원칙

1. 업무 데이터가 장식보다 먼저 보이도록 한다.
2. 주요 숫자는 크게, 설명은 작고 흐리게 표시한다.
3. 검토·미배정·실패 항목은 상태 배지로 빠르게 구분한다.
4. 표는 셀 간격을 좁게 유지하되 행 hover로 추적성을 높인다.
5. 기본 동작은 검정 버튼, 보조 동작은 흰색 버튼으로 통일한다.
6. 그랜터의 로고·상표·고유 이미지 자산은 복제하지 않고, 레이아웃과 사용성 패턴만 업무 시스템에 맞춰 재구성한다.

## 주요 변경 파일

## 반응형 기준

- 1200px 이하: 요약 카드 3열
- 900px 이하: 상세 사이드바 슬라이드 메뉴
- 640px 이하: 아이콘 레일 제거, 모바일 헤더 사용
