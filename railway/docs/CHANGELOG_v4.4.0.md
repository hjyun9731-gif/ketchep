# v4.4.0 통합 안정화

- 회원별 signed balance 통일: `40,000원 / 0원 / -40,000원`
- 미수금 화면을 부과건 목록에서 회원별 최종잔액 목록으로 변경
- 지역·계정·미수/완납/선납·금액·미납기간·최근입금일 필터 추가
- 문자 대상도 선납 상계 후 실제 양수 잔액만 사용, 미납기간/최근입금일 필터 추가
- 농협 입금대조 초기화는 현재월 **농협 복붙 거래만** 대상, 초기화 건수/배정건수 사전 표시
- 농협 중복 fingerprint에 거래구분 추가
- 회원검색 `ASSOCIATION_DUE` 잘못된 enum 제거
- 신규 30,000/50,000원 미등록 입금을 자격증명 후보로 처리하는 화면 추가
- 배 차량 50,000원은 발급비 30,000 + 관리비 선납 20,000 자동 분리
- 신규 자격증명 처리 후 `협회관리시스템 예정자 등록 필요` 표시
- 카드 결제취소가 후속 파일에서 들어오면 기존 회원 입금배정을 자동 원복
- 알토란/사이다페이 실제 헤더 회귀테스트 추가
- 폐업 팝업에 signed 잔액, 선납금, 환불대기 생성 여부 표시
- 미수금 완성본의 선납을 별도 양수 칸이 아니라 음수 현재잔액으로 통일
- 성능 인덱스 추가
