# v4.3.2

- NH 농협 표 전체 복붙에서 거래후잔액(예: 35,805,145)을 입금액으로 잘못 읽던 오류 수정.
- 헤더 없는 NH 입금내역은 `거래일 → 입금액 → 거래후잔액 → 거래구분 → 입금자명 → 상대은행/계좌` 구조를 우선 인식.
- `35.805.145` 같은 점(.) 천단위 표기도 정상 금액으로 파싱.
- 입금자명 대신 `농협 301059`, `카카오뱅크 0900032` 같은 상대은행/계좌 문자열을 잡던 휴리스틱 수정.
- 입금 확인 회원 선택은 3,700명 드롭다운을 렌더링하지 않고 AJAX 검색형 자동완성만 사용.
- 회원명단은 `수정 / 입금 / 폐업` 3버튼만 유지하고, `폐업` 클릭 후 `폐업 / 도내 양도 / 타지역 이관` 선택 팝업 유지.
- 주소·잔액·관리 열 간격 축소 및 signed 잔액(`-40,000원`) 표시 유지.
