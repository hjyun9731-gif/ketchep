# v3.0.3 — 기존 자료 불러오기 수정

- 전체면허자현황의 첫 보조 시트만 기준으로 열을 고정하던 오류 수정
- 실제 원본의 `개인`, `택배` 시트를 각각 자기 제목행 기준으로 읽도록 변경
- `업체세분`, `선진물류`, `업체`, `차량집계` 보조 시트 자동 제외
- `핸드폰` 열을 일반 전화번호보다 우선 사용
- 이름 내부 공백 정규화
- 현재연도 `회비내역` 시트만 선택
- 미래의 빈 월을 제외하고 값이 있는 가장 최근 `N월 미수금` 자동 선택
- 미수금 파일의 축약 차량번호를 이름 + 차량 끝 4자리로 대조
- 음수 미수금은 선납금으로 이관
- 비고·지역·계정을 회원정보에 함께 반영
- 실패 시 사용자의 파일을 탓하는 문구 대신 실제 누락 시트/열 표시
