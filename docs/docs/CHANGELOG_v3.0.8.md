# v3.0.8

- 회원 수정·폐업을 명단 위 팝업으로 변경
- 회원 행에 수기입금 버튼 추가
- 수기입금이 미수금, 통장 K~O, 입금전표에 함께 반영
- 내부용 부과기준/시스템등록일/확인상태 입력란을 회원 수정화면에서 제거
- `18.10.24.`, `13. 6. 3.` 같은 원본 날짜의 마지막 점 때문에 가입일·자격증명 발급일이 누락되던 오류 수정
- 배포 시 기존 ParsedRow로 가입일·자격증명 발급일 자동 복구; 일반적으로 원본 재업로드 불필요
- 현재명단 페이지에서 전체 회원 대상 상관 서브쿼리와 차량번호 정렬 제거
- 현재 페이지 50명에 대해서만 차량번호·미수금 3개 집계쿼리 실행
- 회원 상세의 부과별 N+1 정산 조회 제거
