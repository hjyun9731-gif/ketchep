# 화물협회 입금대조·미수금·입금전표 자동화 개발명세 v2.0

## 1. 시스템 목적

기존 협회관리시스템을 대체하지 않는다. 신규 프로그램은 다음 업무를 자동화한다.

1. 농협 계좌 3개 입금내역 수집
2. 입금자와 회원·차량 자동대조
3. 미수금 입금액·입금날짜 반영
4. 통장 K~O열 작성
5. 입금전표 작성
6. 카드결제 반영
7. 현재명단·폐업명단·미수금·선납금 관리
8. 문자·환불·내용증명 후속관리

## 2. 사용자와 운영환경

- 공용 계정 1개: `admin`
- 기본 비밀번호: `admin1234`
- 모든 변경이력 작업자: `admin`
- Django + PostgreSQL
- GitHub Private 저장소
- Railway 배포
- 개인정보 뒷자리 저장 금지

## 3. 첫 화면

로그인하면 월 작업 생성 화면이 아니라 `오늘 입금대조`가 열린다.

### 필수 구성

- 농협 계좌 1 붙여넣기
- 농협 계좌 2 붙여넣기
- 농협 계좌 3 붙여넣기
- 오늘 신규 입금 건수·금액
- 이번 달 자동매칭 건수
- 확인 필요 건수
- 현재 미수금
- 확인 필요 거래 목록
- 최근 처리 거래 목록
- 3종 Excel 다운로드

사용자가 월 작업 버전, 시트, 헤더 행, 열 매핑을 선택하지 않는다.

## 4. 농협 입금내역 입력

### 4.1 실제 작업 방식

- 계좌별로 농협 엑셀을 연다.
- 표 전체를 복사한다.
- 프로그램의 해당 계좌 칸에 Ctrl+V 한다.
- 3개 계좌를 각각 붙여넣는다.

### 4.2 조회기간

- 8월 3일 작업: 8월 2일~3일
- 8월 4일 작업: 8월 3일~4일
- 월요일 작업: 금요일~월요일

조회기간이 겹치는 것이 정상이다.

### 4.3 자동 인식

- 제목행
- 계좌번호행
- 빈 행
- 합계행
- 거래일시
- 입금자명
- 입금액
- 잔액
- 거래번호

열 순서가 바뀌어도 헤더명으로 인식한다. 인식 실패 시 시트·열 설정 화면을 띄우지 않고 `농협 엑셀 표 전체를 다시 복사`하도록 안내한다.

### 4.4 중복 방지

다음 자료를 조합한다.

- 붙여넣은 계좌 1·2·3
- 거래일시
- 입금자명 원문
- 입금액
- 거래 후 잔액
- 거래번호
- 동일거래 발생 순번

같은 거래가 다음날 다시 포함되면 제외한다. 실제로 동일한 사람이 같은 금액을 두 번 입금한 경우, 동일 행의 발생 개수로 구분해 각각 보존한다. 구별자료가 부족하면 삭제하지 않고 중복 의심으로 둔다.

## 5. 입금자 자동매칭

### 5.1 검색자료

- 현재 차량번호
- 과거 차량번호
- 회원명
- 미수금 비고
- 회원 비고
- 사용자가 저장한 입금자 별칭
- 폐업회원 자료

### 5.2 문자열 정규화

- 공백 제거: `한 순 례` → `한순례`
- 괄호·하이픈·`호` 등 불필요 문자 제거
- 차량번호에서 한글 용도문자와 숫자 추출
- 4자리 이상 숫자에서 끝 4자리 추출
- 입금자 원문은 별도로 그대로 보존

### 5.3 처리 예

- `1423홍길동`: 이름 + 차량 끝번호
- `홍길동1423`: 이름 + 차량 끝번호
- `1423`: 끝번호가 전체에서 유일하면 자동
- `81배1845`: 현재·과거 차량번호
- `김창훈1116호`: 이름 + 끝번호
- `가뭔1025`: 1025 끝번호가 유일하면 자동
- `한 순 례`: 이름 또는 비고 검색
- `신평`: 비고에서 찾되 사용자 확인

### 5.4 자동매칭 우선순위

1. 사용자가 저장한 계좌별 입금자 별칭
2. 현재·과거 전체 차량번호
3. 이름 + 차량번호 일부
4. 미수금 비고 이름 + 차량번호 일부
5. 현재·과거 차량 끝번호가 전체에서 유일
6. 회원명이 전체에서 유일
7. 미수금 비고 이름 단독

### 5.5 자동처리 금지

- 동명이인
- 끝번호 후보 복수
- 이름과 차량번호 충돌
- 미수금 비고 단독 일치
- ATM·CD·일반이체·지로 등 식별정보 없음
- 오타 유사도만 높은 경우
- 후보 없음

미수금 비고에서 한 명만 찾아져도 화면에 추천회원과 근거를 보여준 후 사용자가 확정한다.

### 5.6 별칭 학습

수동 확정 시 선택항목:

- 이번 건만 반영
- 앞으로 같은 계좌의 같은 입금자명 자동매칭

한 입금자가 여러 회원의 돈을 대신 낼 수 있으면 별칭을 저장하지 않는다.

## 6. 계정과 반영

### 6.1 정기 계정

한 사람은 협회비 또는 관리비 중 하나만 가진다. 동시에 존재할 수 없다.

미수금의 지역·계정·비고·이름을 통장과 전표에 사용한다.

### 6.2 통장 K~O

- K 지역
- L 차량번호
- M 이름
- N 계정
- O 금액

### 6.3 미수금

같은 회원이 한 달에 여러 번 입금하면:

- 입금액: 모두 합산
- 입금날짜: 건별로 모두 기록
- 같은 날 두 번이면 `08.05, 08.05`

### 6.4 입금전표

필드:

- 전표번호
- 입금일자
- 입금계좌
- 입금자명
- 지역
- 차량번호
- 회원명
- 차변계정
- 대변계정
- 금액
- 적요
- 처리상태
- 원본거래ID

기본 차변은 보통예금이다. 미배정은 가수금이다. 한 거래가 여러 회원 또는 여러 계정이면 같은 전표번호로 여러 줄 생성한다. 분할합계는 원입금액과 일치해야 한다.

## 7. 현재명단과 폐업명단

### 7.1 현재명단

- 정상
- 최초 부과 전
- 완납
- 미수금 있음
- 선납금 있음

신규 등록 즉시 명단에 표시한다. 최초 부과일 전까지 부과금은 0원이다.

### 7.2 폐업명단

폐업 처리 즉시 현재명단에서 제외하고 폐업명단으로 이동한다.

- 과거 부과·입금 유지
- 기존 미수금 유지
- 폐업 후 입금 가능
- 선납금 환불대기
- 폐업자용 문자
- 재등록 연결

폐업자료는 삭제하지 않는다.

## 8. 신규 명단 추가

최소 입력:

- 지역
- 차량번호
- 성명
- 비회원/협회가입
- 자격증명 발급일 또는 협회 가입일
- 필요한 경우 비고의 다른 입금자명

비회원이면 관리비 계정, 협회가입이면 협회비 계정을 자동설정한다. 상세 연락처·주소는 나중에 보완할 수 있다.

## 9. 자격증명 발급 흐름

실제 업무:

1. 종이 자격증명 발급신청서 접수
2. 자격증명 발급비 입금 확인
3. 돈 낸 사람만 기존 협회관리시스템 예정자 입력
4. 자격증명 발급
5. 발급한 자격증명을 시청에 팩스
6. 시청 신규 인가 공문 수신
7. 기존 협회관리시스템에서 신규등록
8. 개인회원 또는 택배회원으로 구분

새 프로그램은 입금·미수금용 명단을 관리하지만 기존 협회관리시스템에 직접 쓰지 않는다.

### 발급비

- 협회가입자: 면제
- 비회원 `배`: 30,000원
- 비회원 비`배`: 50,000원

`배` 비회원이 50,000원을 내면 발급비 30,000원 + 관리비 선납 20,000원으로 분할할 수 있다.

## 10. 개별 부과일

### 협회비

- 가입 당월 없음
- 실제 가입일 한 달 뒤 같은 날짜 최초 부과
- 이후 매월 같은 날짜
- 없는 날짜는 말일

### 관리비

- 자격증명 발급 당월 없음
- 발급일 한 달 뒤 같은 날짜 최초 부과
- 이후 매월 같은 날짜
- 없는 날짜는 말일

### 예

- 8월 2일 발급 → 9월 2일 최초 부과
- 8월 30일 가입 → 9월 30일 최초 부과

월초 일괄 부과하지 않는다. 오늘 이후의 미래 부과일은 미리 원장에 올리지 않는다.

### 기존 확정규칙

- 2026년까지 비회원 관리비 월 부과 대상은 `배`
- 2027년 1월부터 모든 비회원 관리비 5,000원
- 기존 비회원은 2027년 1월 1일 최초 부과
- 2027년 이후 신규 비회원은 발급일 기준
- 발급일 지연입력 시 소급부과 금지
- 협회비 10,000원
- 70세가 되는 연도 1월부터 협회비 5,000원

## 11. 폐업

- 폐업일 즉시 입력 가능
- 폐업월 부과 제외
- 이미 발생한 폐업월 부과 취소
- 이후 부과 중지
- 기존 미수금 유지
- 선납금은 환불대기

## 12. 협회 가입·탈퇴

### 가입

- 관리비 미수금 완납 후 가입 가능
- 가입일 실제 날짜 사용
- 가입월 협회비 없음
- 한 달 뒤 같은 날짜 최초 협회비
- 관리비 계정 종료, 협회비 계정으로 전환

### 탈퇴

- 협회비 미수금 완납 후 탈퇴
- 탈퇴월 협회비 취소
- 2026년 `배`는 탈퇴월부터 관리비
- 2026년 비`배`는 관리비 없음
- 2027년부터 모든 탈퇴자가 관리비 대상

## 13. 카드결제

- 알토란·사이다페이 각각 엑셀 업로드
- 차량번호 항상 존재
- 차량번호 우선, 이름 검증
- 충돌 시 확인 필요
- 총결제액을 회원 미수금에 반영
- 농협 순정산입금은 회원에게 재반영하지 않음
- 수수료 = 총결제액 - 순정산액
- 사이다페이 승인번호·거래번호 우선 중복키
- 알토란은 일시·차량·이름·금액 조합

## 14. 입금 취소·재배정

- 기존 배정 취소 시 과거 회원 미수금·선납금 원상복구

- 전후 회원, 계정, 금액, 사유, 시간, 작업자 기록
