- [ ] `.xlsx` 업로드

## 부과
- [ ] 2026년 비가입 `배` 차량 관리비 5,000원
- [ ] 2026년 비가입 비택배 차량 월부과 없음
- [ ] 2027년 1월 기존 비가입자 전원 5,000원
- [ ] 2027년 신규 비가입자 발급일 한 달 뒤 같은 날짜부터 5,000원
- [ ] 70세 도달 연도 1월부터 협회비 5,000원
- [ ] 폐업월·재등록월 부과 없음
- [ ] 가입일 한 달 뒤 협회비 시작
- [ ] 관리비 미수금이 있으면 가입대기
- [ ] 협회비 미수금이 있으면 탈퇴 불가

## 입금
- [ ] 전체 차량번호 자동매칭
- [ ] 이름+차량번호 일부 자동매칭
- [ ] 동명이인 확인 필요
- [ ] 한 입금을 2명 이상 분할
- [ ] 한 입금을 자격증명+관리비 등 여러 계정으로 분할
- [ ] 일부납부는 오래된 미수금부터 충당
- [ ] 초과입금은 선납금
- [ ] 잘못 배정한 입금 재배정 시 원상복구
- [ ] 카드 순정산 입금 이중 반영 방지
- [ ] 파일 간 동일 거래 중복 의심 표시

## 폐업·환불
- [ ] 폐업월 부과 취소
- [ ] 선납금이 있으면 환불대기

- [ ] 완료 후 나중에 별도 환불문자 발송 가능
