# v2.0.0 Daily Reconciliation

## 업무 흐름 변경

- 월 작업 생성 중심 화면을 제거하고 로그인 첫 화면을 일일 입금대조로 변경
- 농협 계좌 3개 엑셀 전체 복사·붙여넣기 지원
- 겹치는 조회기간 중복 방지
- 제목행·계좌번호행·빈 행 자동 제외
- 확실한 거래 즉시 미수금 반영, 애매한 거래만 확인

## 매칭 강화

- 현재·과거 차량번호 검색
- 차량 끝번호 단독 유일매칭
- `1423홍길동`, `1423`, `가뭔1025` 형태 지원
- 미수금 비고의 자유형 이름 검색
- 비고 단독 일치는 수동 확인
- 계좌별 입금자 별칭 학습

## 명단·부과

- 현재명단과 폐업명단 분리
- 신규 명단 간편추가
- 회원별 미수금 계정 저장
- 개인별 부과일 기준
- 미래 부과일 사전 부과 금지

## Excel

- 월 다운로드를 통장·미수금·입금전표 3개 ZIP으로 변경
- 통장 K~O를 지역·차량번호·이름·계정·금액으로 고정
- 미수금 입금일자를 건별 중복 포함 기록
- 입금전표와 계정별 합계 자동 생성

## UI

- 그랜터 계열 재무업무 SaaS의 정보구조와 시각 문법 참고
- 고유 상표·로고·그래픽 미사용
- 일일 붙여넣기 카드, 확인 필요 큐, 업무 바로가기 중심 구성
