# v4.3.1

- 회원명단 잔액을 부호 그대로 표시: 미수 40,000원 → `40,000원`, 선납 40,000원 → `-40,000원`.
- 주소/잔액/관리 열 간격 축소 및 관리 버튼 밀도 조정.
- 명단의 `폐업` 버튼은 `폐업 / 도내 양도 / 타지역 이관` 선택 팝업을 유지.
- 회원 성명을 클릭하면 페이지 이동 없이 `2026년 1~7월 입금내역` 팝업 표시.
- 기존 미수금 파일의 `1월~7월 입금액/입금날짜`를 조회 전용 이력 테이블로 자동 복구.
- 과거 입금이력은 live Payment 원장과 분리하여 현재 미수금/선납금 계산에 영향을 주지 않음.
- 3월 등 원본 날짜가 `#######`로 손상된 경우 `원본 날짜 확인불가`로 표시.
- 배포 시 최신 미수금 업로드 자료에서 1~7월 이력을 자동 backfill.
- 현재명단/폐업명단 엑셀 다운로드의 잔액도 음수 선납을 포함한 signed balance 한 열로 통일.
