# v4.3.0

## 입금 확인 회원 선택
- 3,000명 이상 회원을 `<select>`에 전부 렌더링하던 구조 제거.
- 이름, 차량번호, 관리번호, 전화번호, 생년월일로 검색하는 AJAX 자동완성 적용.
- 검색 결과는 최대 20명만 표시하며 선택 후 회원 ID만 저장.
- 키보드 위/아래/Enter 선택 지원.

## 명단 밀도 및 업무 버튼
- 주소 열 폭 축소, 잔액/관리 열을 주소 바로 옆에 붙여 배치.
- 관리 버튼을 `수정 / 입금 / 폐업` 3개로 축소.
- `폐업` 클릭 시 팝업에서 `폐업 / 도내 양도 / 타지역 이관` 선택.

## 선납 표시
- 현재 페이지 회원의 Prepayment 잔액을 별도 집계.
- 미수금이 있으면 `미수`, 음수 기초잔액으로 생긴 선납이 있으면 `선납`으로 표시.
- 회원 명단 Excel에도 미수금과 선납금을 별도 열로 출력.

## 미수금 문자 필터
- 지역, 계정, 미수금액 구간을 기본 필터에 추가.
- 가입상태, 현재/폐업, 연락처, 연락상태, 최소/최대 미수금을 추가조건으로 제공.
- 선납/완납 회원은 미수금 문자 대상에서 제외.
