# v2.0 인수시험

## A. 일일 붙여넣기

1. 계좌 1 표 전체 붙여넣기 시 신규 입금 생성
2. 같은 자료 재붙여넣기 시 중복반영 0건
3. 전날+오늘 겹친 자료에서 오늘 신규만 생성
4. 같은 사람이 같은 금액 두 번 입금한 두 행은 2건 보존
5. 계좌번호가 없는 자료도 붙여넣은 칸으로 계좌 구분
6. 제목행·빈 행·합계행 미생성

## B. 매칭

1. `1423홍길동` 이름+끝번호 자동
2. `1423` 유일 끝번호 자동
3. `가뭔1025` 유일 1025 자동
4. 동명이인 이름만 있으면 확인 필요
5. 끝번호 복수면 확인 필요
6. 이름과 차량번호 충돌 시 확인 필요
7. 비고 `한 순 례` 단독 일치 시 추천만 표시
8. 수동 확정 후 별칭 저장 시 다음 거래 자동
9. 폐업회원의 과거 차량번호 입금도 해당 폐업회원과 대조

## C. 반영

1. 확정 거래 미수금 입금액 합산
2. 입금날짜 건별 중복 기록
3. 통장 K 지역, L 차량, M 이름, N 계정, O 금액
4. 입금전표 자동 생성
5. 한 거래 두 계정 분할 시 같은 전표번호 두 줄
6. 미배정액이 있으면 가수금 전표

## D. 명단

1. 신규 등록 후 현재명단 즉시 표시
2. 최초 부과일 전 부과 0원
3. 폐업 즉시 현재명단 제외
4. 폐업명단 표시 및 기존 미수금 유지
5. 재등록 시 현재명단 복귀 및 과거 기록 유지

## E. 부과

1. 8월 2일 발급 → 9월 2일 최초 관리비
2. 8월 30일 가입 → 9월 30일 최초 협회비
3. 9월 1일에 위 신규자에게 부과되지 않음
4. 미래 날짜 부과 미리 생성하지 않음
5. 폐업월 이미 생성된 부과 자동 취소
6. 협회비와 관리비 동시 발생 없음

## F. 카드

1. 차량번호 정확 일치 자동
2. 차량번호·이름 충돌 확인 필요
3. 총결제액 미수금 반영
4. 농협 순정산입금 이중반영 없음
5. 같은 파일 재업로드 중복 없음

## G. 출력

1. 월 ZIP에 통장·미수금·입금전표 3개 존재
2. 통장 K~O 위치 확인
3. 미수금 날짜 중복 기록 확인
4. 입금전표 계정별 합계와 거래 합계 일치
5. 주민번호 뒤 7자리 없음
