# v3.0.0 전체 UI/UX 재구축

부분 수정이 아니라 사용자 화면 전체를 하나의 업무형 디자인으로 다시 구성했습니다.

## 공통
- 이중 사이드바와 과도한 가로형 입력 제거
- 최대 1160px 중앙 정렬 업무 화면
- 상단 주 메뉴 5개: 입금대조, 명단, 카드결제, 미수금, 문자
- 자료 불러오기·환불·내용증명·변경이력은 관리 메뉴로 정리
- 화면마다 제목, 설명, 주 작업 버튼 위치 통일
- 검색은 짧은 기본 검색과 필요한 경우에만 여는 추가 조건으로 분리
- 표, 상태표시, 버튼, 폼, 빈 화면 디자인 전면 통일

## 전면 재구축 화면
1. 로그인
2. 입금대조 첫 화면
3. 입금 처리내역
4. 애매한 입금 확인·재배정
5. 현재명단
6. 폐업명단
7. 회원 상세
8. 신규등록·회원수정 및 각 업무 폼
9. 기존 자료 불러오기
10. 카드결제 업로드·내역
11. 미수금 목록
12. 문자 업무 선택
13. 미수금 문자 대상선택·발송설정
14. 환불 문자 대상선택·발송설정
15. 문자 최종확인
16. 환불관리
17. 내용증명
18. 변경이력
19. 월 작업 상세·파일 업로드·열 연결 고급 화면

## 업무 원칙
- 기능을 삭제하지 않고 자주 쓰는 작업을 앞에 배치
- 기존 명단은 엑셀 2개로 최초 일괄 이관
- 폐업자는 현재명단에서 빠지고 폐업명단으로 이동
- 농협 3개 계좌는 계좌별 붙여넣기
- 알토란·사이다페이는 파일 업로드가 화면 첫 작업
- 문자발송은 대상 선택 → 발송 설정 → 최종 확인 순서
